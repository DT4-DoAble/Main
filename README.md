## 서비스 개요
<details>
<summary>
Doable

Doable은 일정 관리에 부담을 느끼는 사용자들도 ‘할 수 있다(Doable)’는 자신감을 느낄 수 있도록 설계된 간단하고 직관적인 캘린더 서비스입니다.
학업, 직장 등 바쁜 일상을 보내는 사용자들이 쉽고 자연스럽게 일정 관리의 습관을 형성하도록 돕는 것을 목표로 합니다.
</details>


## 문제 정의 (서비스 목적)

### 문제 상황
많은 사람들이 바쁜 일상 속에서 일정 관리를 필요로 하지만, 대부분의 일정 관리 도구는 복잡한 기능과 높은 진입 장벽으로 인해 꾸준히 사용하기 어렵습니다. 특히, 일정 관리가 습관화되지 않은 사용자들은 이러한 도구를 시도했다가 포기하는 경우가 많습니다.

### 목표 사용자
* 일정 관리의 필요성을 느끼지만 습관화된 도구 사용에 어려움을 겪는 사람들.
* 학업, 취업 준비, 첫 직장 생활 등으로 인해 시간 관리에 대한 심리적 부담이 큰 사용자.
* 복잡한 앱 사용 대신 간단하고 직관적인 방식을 선호하는 사용자.

  
### 문제의 근본 원인

1. 일정 관리 앱의 기능이 지나치게 복잡하여 진입 장벽이 높음.
2. 기존 도구들은 주로 성과에 초점을 맞추며, 작은 성공 경험을 제공하지 못함.
3. 사용자들은 알림이나 입력 과정을 부담스러워하며 빠르게 이탈함.
   
### 서비스의 필요성
Doable은 기존 일정 관리 도구의 복잡성을 제거하고, **"작은 성공 경험"과 "AI 기반 제안"**을 통해 심리적 부담을 낮춥니다. 이를 통해 사용자가 자연스럽게 일정 관리 습관을 형성하고, 더 나아가 삶의 질을 향상시킬 수 있도록 돕습니다.
